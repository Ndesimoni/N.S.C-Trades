Two shapes added

Harami and marching joined the shapes rung 3 trades today, and both new size floors went in with them. These are real examples the code now calls setups — the shaded candles are the shape, and the dashed pair shows what the size test measured.

REAL CANDLES. Interactive Brokers. Every one found by pattern::ending_at with config/patterns.toml as it stands after today's change, so the floors are on. Two of each kind, never twice from one pair.

The level half is NOT tested here, and it is half the setup. Every level you have drawn is weekly or daily, and only 1-hour and 4-hour candles are on disk — so a band cannot be sized without guessing at a daily candle, which this project refuses to do. These are the shapes, not the signals.

One --bin history run with TWS up closes that gap.

NOTHING HERE IS MEASURED FOR WORTH. These are shapes the code now finds, drawn so you can say whether they are the ones you would take. Whether they make money needs nsc-backtest, which does not exist.
