Three it refuses

Near misses are worth seeing, because they are what the thresholds are actually for. The first one is a gap that was in the code until an hour ago.

The two waiting on you

Both are stubbed in the code and neither is built. They were in the original scaffolding and are not on your list of six — so the question is simply whether you trade them.

What happens either way

If you do not trade them, both stubs get deleted and the code stops implying they are coming. That is the tidier outcome.

If you do, they get captured the way the other six were — your words first, then the code. The star would be the first three-candle shape in the project: everything built so far handles one candle or two, and the finder only ever looks at the newest pair.

A reminder about the numbers on this page

Every threshold shown — tail twice the body, doji under 5%, body at least 60% for a belt-hold — is textbook, not yours. They were taken as standard defaults so the detectors could be built.

What replaces them is a pair of charts: one setup you took, and one you passed that looked the same. Until then nobody should read 2.0 and assume somebody chose it.

A diagram is an argument, not evidence. It shows what the code calls each shape; whether those shapes make money needs a backtest over real candles, which this project cannot run yet.
