A swing is proved by the pullback, not by counting candles

Your rule, drawn out: a peak counts once price has given back around half of the run that made it — or near half, if price then takes the peak out. This is the whole of what the swing finder becomes. Check it against how you actually read a chart before it turns into code.

The rule

The run is the move from the last low up to the peak. The peak becomes a swing high the moment price gives half of that run back.

The other way a peak proves itself

A pullback that stops near half and then runs again is still a real turn. In a strong trend that is the normal case — price barely pauses before going on. So depth is one way to confirm a peak, and price taking that peak out is the other.

What it accepts, and what it now refuses

Both of these peaks beat the three candles either side, so today's code calls both of them swings. Under your rule only one is.

Swings alternate, and you learn about each one late

Because the finder looks for a low after a high, the output is the zigzag you would draw by hand. The gap between where a swing sits and when it can be used is not fixed any more — it is however long the pullback took.

The floor: a run is judged against recent runs

Half of a tiny run is a tinier pullback, so on its own the rule would find structure in a quiet Tuesday afternoon. A move only counts as a move next to the moves around it — at least half of them, and up to three quarters if you want it stricter.

What this is all for

Trend. Higher highs and higher lows is an uptrend, lower highs and lower lows is a downtrend, and there is no way to say either sentence without swing points to count.

Which is why the shallow-pullback case above is not a detail. Trend strength shows up as pullback depth — the stronger the move, the less it gives back. A rule that only recognised deep pullbacks would see structure clearly in choppy markets and go blind in clean trending ones.

It is also the same measurement Fibonacci uses. The run is the leg, the pullback is the retracement, and ta.toml already calls 0.382 to 0.618 the zone you trade. "Near half" sits inside that by definition.

The whole rule, as settings

Four numbers, all of them ratios, none of them in pips. Which is why the same four work on the 4-hour and the daily, and on gold and EURUSD.

confirm_retracement = 0.5 — a pullback this deep proves the peak on its own.
shallow_retracement = 0.382 — this deep counts once price takes the peak out. The same number as your strong-trend Fibonacci level, because it is the same situation.
min_run_fraction = 0.5 — how big a run must be next to recent ones. Your range is 0.5 to 0.75; it starts loose.
run_memory_legs = 5 — how far back "recent" reaches.

One thing is still open, and it does not block the code: whether major and minor swings need separating. That changes what the finder hands back, not how it decides, so it can be added later without undoing any of this.
