When a higher high is really a higher high

Taking out the old high is not enough. Price has to carry at least 40 to 50% of the previous run past it — measured from the take-out — before the market has actually gone somewhere. This is what that looks like, and what it refuses.

candles ATR swings levels structure

The rule

The previous run is 200 points, from 1900 up to 2100. Everything is measured against that.

What it refuses

Same setup, same old high. The difference is what happens after the line is crossed.

Why it is measured from the high, not the pullback

There were two places the 40% could have been measured from. Only one of them asks a real question.

Still to come: option 2

This was described as option 1, so there is at least one other way a higher high gets accepted. It has not been captured yet.

One thing is still open with it: the in-between case, where price takes the high and stalls at 20% of the run. Not a higher high — but is it nothing, or is it worth recording as a failed attempt?

Lower lows are settled: exactly the same rule, mirrored. Break the previous low, then carry 40 to 50% of the previous run below it. One piece of code with a direction passed in — an uptrend and a downtrend judged by different rules is how a bot ends up bullish and bearish about the same chart.

One setting has to go

ta.toml already answers this question a different way: [structure] bos_atr_multiple = 0.3 — how far past an old high price must push, measured in normal candles rather than as a fraction of the run.

Two settings for one question is how they end up disagreeing. The fraction-of-the-run version fits everything else you have described, where the yardstick is always the move in front of you.

A diagram is an argument, not evidence. It shows what the rule does; whether it makes money needs a backtest over real candles, which this project cannot run yet.
